# CONSIGNA

Partís del sistema de estudiantes que ya funciona (base de datos \+ API PHP \+ fetch \+ DOM). Tu trabajo: convertirlo en un sistema de productos y después mejorarlo.

Cada producto tiene nombre, precio y stock. Todo debe funcionar sin recargar la página: listar, buscar, agregar, editar y eliminar.
